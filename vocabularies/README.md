# BCDH SKOS Vocabularies Collection

This directory contains semantic SKOS vocabularies managed and developed by the BCDH team. Each vocabulary is organized into its own dedicated sub-directory with its own documentation.

---

## 📂 Available Vocabularies

### 1. **[HECTOR Epoch SKOS Vocabulary](hector_epochs/README.md)**
* **Directory:** `hector_epochs/`
* **File:** `hector_epochs/HECTOR_Epoch.ttl`
* **Description:** An integrated archaeological epoch vocabulary comprising core baseline epochs, Roman emperors, medieval dynasties and rulers (HRR, England, France, Spain, Italy), Ancient Egypt dynasties/pharaohs, and a fine-grained chronological grid.
* **Namespace:** `http://vocabs.bcdh.uni-bonn.de/hector_epochs/`

### 2. **[HECTOR 3D Documentation SKOS Vocabulary](hector_3d_documentation/README.md)**
* **Directory:** `hector_3d_documentation/`
* **File:** `hector_3d_documentation/HECTOR_3D_Documentation.ttl`
* **Description:** A hierarchical technical documentation and processing vocabulary for 3D modeling, photogrammetry, structured light scanning, 3D file formats, and hardware devices.
* **Namespace:** `http://vocabs.bcdh.uni-bonn.de/hector_3d_documentation/`

### 3. **[BCDH Heritage Assets SKOS Vocabulary](heritage_assets/README.md)**
* **Directory:** `heritage_assets/`
* **File:** `heritage_assets/heritage_assets.ttl`
* **Description:** Comprehensive multilingual SKOS vocabulary classifying cultural heritage assets, ancient ceramics, vessels, architecture, sculpture, ornament, myth, realia, botany, zoology, and materials.
* **Namespace:** `http://vocabs.bcdh.uni-bonn.de/hector_heritage_assets/`
